# Physical Layer Modeling using Synchronous Machine Learning Techniques

## Finite Element Modeling and Deep Learning Surrogate Prediction of Knee Meniscus Biomechanics

This repository contains the code developed as part of my thesis, **“Physical Layer Modeling using Synchronous Machine Learning Techniques.”**

The project combines finite element modeling of the human knee in FEBio with deep learning for the prediction of the mechanical response of the medial and lateral menisci.

The complete computational workflow includes preprocessing and modification of the finite element knee model, remeshing of anatomical structures, generation of walking-related loading cases, extraction of biomechanical results from FEBio, construction of an image-based dataset, and development of a U-Net-based surrogate model.

Finite element simulations were performed under time-dependent loading conditions representative of walking, combining compressive loading with knee flexion–extension throughout the gait cycle. The resulting mechanical response of the menisci was exported as grayscale spatial field maps and used as ground-truth data for neural-network training.

The objective of the surrogate model is to approximate the spatial biomechanical fields generated by FEBio while requiring substantially less computational time once the network has been trained.

---

## Finite Element Modeling Workflow

The finite element component of the project was developed using FEBio.

The preprocessing stage includes scripts used during preparation and modification of the knee model, including:

- Preparation and modification of model geometry
- Conversion or replacement of selected ligament representations with spring-based elements
- Remeshing of selected anatomical structures
- Preparation of the final model used for the FEBio simulations

The model was subsequently simulated under different combinations of compressive loading and knee flexion.

Walking-related simulations were complemented by additional loading cases in order to increase the range of mechanical conditions represented in the dataset.

The main quantities extracted from the menisci were:

- Z-displacement
- Effective Lagrange strain
- Von Mises stress
- Contact pressure

## Deep Learning Surrogate Model

The surrogate model is based on a 2D U-Net convolutional neural network with scalar conditioning at the bottleneck.

The network learns a mapping between the geometric and loading information describing a simulation state and the biomechanical response obtained from FEBio.

### Model Inputs

For each simulation state, the neural network receives two spatial inputs:

- **Meniscus mask** – binary image defining the meniscal region
- **Reference height map** – grayscale representation of the initial meniscus geometry

Three scalar variables are also provided:

- **Time** (`t`)
- **Normalized compressive force** (`F_norm`)
- **Normalized knee flexion angle** (`theta_norm`)

The scalar variables are processed using a multilayer perceptron and incorporated into the latent representation of the U-Net at the bottleneck.

### Model Outputs

The network simultaneously predicts four spatial biomechanical fields:

1. **Z-displacement**
2. **Effective Lagrange strain**
3. **Von Mises stress**
4. **Contact pressure**

Each quantity is predicted as a two-dimensional field map corresponding to the FEBio-derived ground-truth representation.

---

## U-Net Architecture

The surrogate model follows an encoder–decoder U-Net architecture consisting of:

- Double convolutional blocks
- Batch normalization
- ReLU activation functions
- Max-pooling operations
- A latent bottleneck representation
- Scalar conditioning through a multilayer perceptron
- Transposed-convolution upsampling
- Skip connections between corresponding encoder and decoder levels
- A final convolutional layer producing four output channels

## Dataset

The neural-network dataset was generated entirely from finite element simulations performed in FEBio.

Each simulation case contains multiple time states describing the evolution of the loading and knee-flexion conditions.

For each state, grayscale images were exported for:

- Z-displacement
- Effective Lagrange strain
- Von Mises stress
- Contact pressure
- Meniscus mask
- Reference height

The corresponding scalar information describes:

- Simulation time
- Normalized compressive force
- Normalized knee flexion angle

All exported images use a consistent view and representation so that corresponding pixels describe the same spatial region throughout the dataset.

### Dataset Availability

The complete FEBio simulation dataset is **not included in this repository** because it contains a large number of simulation outputs and exported image files.

This repository therefore focuses on the source code used for finite element preprocessing, dataset handling, surrogate-model training, evaluation, and visualization.

---

## Training and Evaluation

The dataset is divided **case-wise**, rather than randomly separating individual images from the same simulation.

This ensures that complete simulation cases used for testing remain unseen during model training.

The network is trained using a **masked L1 loss**, so prediction error is evaluated within the meniscal region rather than over the image background.

The **Adam optimizer** is used for network optimization, together with validation-based early stopping.

The model with the best validation performance is saved and subsequently evaluated on independent simulation cases that were not used during training.

## Purpose of the Project

Finite element analysis enables detailed investigation of internal biomechanical quantities that are difficult or impossible to obtain experimentally, including tissue stress, strain, displacement, and contact pressure.

However, detailed nonlinear finite element simulations of the knee are computationally demanding, particularly when many loading conditions and gait-cycle states must be evaluated.

The purpose of the deep learning component of this work is therefore to investigate whether a neural network can learn the relationship between the prescribed loading and kinematic conditions and the resulting meniscal mechanical response.

The trained U-Net acts as a surrogate model of the finite element simulations. It does not replace the underlying physical finite element model; instead, it learns from FEBio-generated solutions and provides a significantly faster approximation for previously unseen conditions within the range represented by the training data.
